Shadow
Engine

A data-driven framework for creating tycoon and idle games in Godot 4.7. It combines visual authoring tools with a renderer-independent simulation core, so game logic and presentation can evolve separately.

A complete foundation for management games.

Shadow Engine handles the systems shared by tycoon projects while leaving each game free to build its own world, art direction, and interface.

  • Visual venue, station, floor, economy, staff, customer, and theme authoring
  • Headless simulation for income, upgrades, hiring, unlocks, production chains, offline earnings, and prestige
  • Validation, safe fixes, project recovery, responsive UI definitions, and export preflight

CURRENT PROGRESS

What is working now

The project is functional and actively being strengthened around its creator workflow and production foundation.

CORE SYSTEMS

Simulation, BigNumber economy, saves and recovery, offline earnings, production chains, objectives, boosts, prestige, and runtime signals are working.

CREATOR WORKFLOW

The editor can build stations and floors, place assets, validate projects, preview venues, and prepare sanitized target exports.

PRESENT FOCUS

I’m building the 1.1 capability foundation, polishing the authoring experience, and hardening the path from project creation to validation and export.
